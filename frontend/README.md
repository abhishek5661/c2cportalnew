# Learnlytica Frontend

This package contains the student-facing interface for Learnlytica. It is intentionally modular, with feature-based folders for the student, mentor, and college flows.

## Local setup

```bash
pnpm install
pnpm --filter @learnlytica/frontend dev
```

## Notes

The frontend is currently the existing Vite + React application, and it is intended to evolve toward the readiness-oriented Learnlytica product loop.
